This page sends live GraphQL requests to /graphql. Edit the queries or inputs and click Run. Results appear below each card. For the full interactive IDE, use GraphiQL.

Queries

user(id) query

Fetch a single user by ID. Returns null if the ID doesn't exist (try id = 99).

— click Run —

users() query

List all users in the in-memory store. Run the mutation below to rename one, then re-run this query to confirm the change.

— click Run —

userWithPosts(id, token) query auth required

Returns a user with their nested posts. The resolver validates the token argument — try wrong-token to trigger a GraphQL error.

— click Run —

Mutations

updateUserName(id, newName) mutation

Renames a user in-memory. After running, execute users() above to see the updated list.
